🐾 AngelsInFur

AngelsInFur is a real-time rescue coordination app that connects animals in need with rescuers, volunteers, and shelters.
Our goal is to make animal rescue faster and easier, giving every paw a chance at safety and love.

✨ Features:- 
Real-time Rescue Alerts – Post and respond instantly to rescue cases.
Volunteer & Rescuer Network – Connect with people who care.
Adoption Support – Help rescued animals find forever homes.
Instant Notifications – Never miss a rescue call.
Journey Cards – Track each animal’s path from rescue to recovery.

🚀 Tech Stack:- 
Flutter (Frontend)
Firebase (Auth, Database, Storage)

🛠️ Setup:- 
Clone the repo
Run flutter pub get
Add your Firebase config files
Run with flutter run
